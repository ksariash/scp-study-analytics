SCP STUDY ANALYTICS — METRIC NOTES
==================================

Unique learners
A count of distinct anonymous installation IDs. This is an estimate: one student can use multiple devices, and multiple students can theoretically share one device.

First-attempt accuracy
Uses events whose local attempt_number is 1. This is the most useful indicator of initial understanding, but students who already answered a question before installing the analytics-enabled version may not contribute a first-attempt event for that question.

Eventually correct
For each anonymous learner + question pair with recorded data, asks whether at least one recorded attempt was correct.

Recovered after miss
Among learner-question pairs with a recorded first attempt that was not correct, the percentage that later recorded at least one correct attempt.

Related audio / glossary use
Recorded only as yes/no flags on the answer event. The system does not upload transcript text, glossary search terms, or detailed listening history.

Location
Derived by Cloudflare from request.cf when the event reaches the analytics Worker. It is approximate IP geolocation, not device GPS. Coordinates are rounded to one decimal place before storage. The dashboard is designed around city/region/country filtering rather than precise positioning.


ZMAN
----
A Zman is the study period. Analytics stores its stable backend ID (for example 2026-summer). The dashboard displays the descriptive topic/date name.

NOTIFICATIONS
-------------
General announcements are not personalized. Issue-resolution notices may be targeted to the anonymous installation ID that submitted the feedback report so the reporting device can see that the issue was addressed. No name or email is required.


Push notifications and study reminders
--------------------------------------
Push reminder subscriptions store the browser endpoint, push keys, active Zman, IANA timezone, reminder time, Israel/Diaspora calendar choice, and broad IP-derived rounded latitude/longitude so Shabbat/Yom Tov boundaries can be evaluated at the subscriber's approximate location. No GPS permission is requested.
The VAPID private key is stored only in D1 and is never returned to the Study app.
